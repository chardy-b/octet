# Octet Automatic AirPlay Implementation Plan

> **For Hermes:** Use Codex Cloud on remote branch `wil-248-airplay`, with exact-head review and CI; do not run code or builds on the controller VPS.

**Goal:** iPhone/Mac casts to Octet through Shairport Sync, automatically selecting the protected DSP path with a −18 dB master startup level.

**Architecture:** Dedicated snd-aloop subdevice 1 carries Shairport PCM to CamillaDSP. Shairport play/end hooks communicate with a narrow local Octet controller serialized against user source changes and Auto Tune. The existing source configuration only changes capture-side routing and rate; filters/output protections stay unchanged.

**Tech Stack:** Raspberry Pi ALSA snd-aloop, Debian Shairport Sync (classic AirPlay), Avahi, CamillaDSP, Python HTTP remote, systemd, unittest/pytest, GitHub Actions.

---

## Global constraints
- **Compatibility:** Preserve MPD on `hw:Loopback,0,0` / Camilla `hw:Loopback,1,0`; AirPlay uses `hw:Loopback,0,1` / `hw:Loopback,1,1`. `snd-aloop pcm_substreams=2` is already configured. Classic package may only support 44.1 kHz; fix Shairport output to 44100/S32_LE/stereo and convert at Camilla input to 48000 DSP with async resampling. Check the Pi's actual binary and devices before enabling.
- **Dependencies:** Shairport Sync and Avahi from OS packages, no AirPlay 2/NQPTP dependency; don't route Shairport directly to DAC8x. No new public HTTP mutation endpoint, credentials, or broad sudo grant.
- **Security and operations:** All hooks local/authenticated and serialized; tune ownership wins; validated approved preset only. On failure/startup/end mute, preserve queue and protective filters/output mutes. Explicit manual source selection remains muted by default; automatic AirPlay startup sets master to −18 dB and then unmutes only when ready.
- **Product contract:** Receiver advertised as Octet, AirPlay auto-selected on play, Tidal pauses without losing queue or auto-resuming. iPhone buttons control Shairport software attenuation, not Camilla master. Show selected AirPlay vs active cast truthfully. LAN discovery only; physical Pi/iPhone acceptance distinct from CI.
