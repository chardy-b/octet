# Octet agent guidance

For web UI, now-playing bridge, browser tests or Pi web deployment, read [the web deployment workflow](docs/agent-workflows/web-deployment.md). For Bluetooth, ALSA Loopback, PipeWire, WirePlumber, BlueALSA, CamillaDSP or other Pi audio changes, also read [the audio deployment gates](docs/agent-workflows/audio-deployment.md) and `pi/remote/README.md` first. Use the current running state as evidence; repository docs do not prove what is active on Octet.

For unrelated work, follow the repository's normal tests and review process; the audio maintenance procedure is not a prerequisite.
